# Human Resource Management System(HRMS) Dalnex

A web application for managing employee records, attendance, leave, payroll, and everyday HR
operations. It includes an administration portal for HR teams and an employee self-service area,
with access controlled by user roles and permissions.

## Features

- **Employee management:** Maintain employee profiles, onboarding, documents, and exit records.
- **Attendance:** Track daily attendance, punch records, holidays, and attendance registers.
- **Leave and approvals:** Manage leave, duty, and compensatory-off requests with approval workflows.
- **Payroll:** Process payroll, calculate salary components and deductions, and generate payslips.
- **Employee self-service:** View personal attendance and pay information, submit requests, and review
  assigned approvals.
- **HR operations:** Manage reimbursements, assets, company policies, notices, and helpdesk tickets.
- **Administration:** Configure users, permissions, application settings, and review audit activity.

## ZKTeco device attendance

The device integration is maintained in [`zkteco/`](zkteco/). Run `npm run dev`
and `npm run device:bridge` in separate terminals, or use `npm run dev:device` to start
both together.

## Source layout

Filenames describe their responsibility. TypeScript and JavaScript use kebab-case;
Python modules use snake_case. Standard names such as `__init__.py` and `requirements.txt`
are retained. `__pycache__` is generated by Python and is not source code.

| Folder | Responsibility and entry points |
| --- | --- |
| `src/lib/db/` | Database access through `server-client.ts`, permissions, payroll processing, and `scheduled-jobs.ts`. |
| `src/lib/excel/` | `export-workbooks.ts`, `parse-monthly-register.ts`, workbook branding, and register styles. |
| `zkteco/admin/link/` | `link-employees.mjs` coordinates planning, saving, and verifying device-to-employee links. |
| `zkteco/admin/onboard/` | `onboard-employees.mjs` coordinates employee creation and updates from the roster. |
| `zkteco/admin/roster/` | `read-employee-workbook.mjs`, `export-device-roster.mjs`, and HRMS roster reconciliation. |
| `zkteco/bridge/` | `attendance_bridge.py` coordinates device polling, the durable attendance queue, and HRMS delivery. |
| `zkteco/cli/` | npm entry points such as `run-device.mjs` and `configure-device.mjs`; `device_cli.py` launches Python commands. |
| `zkteco/server/` | `punch-endpoint.ts`, employee mapping, `record-device-punch.ts`, and device collection setup. |
